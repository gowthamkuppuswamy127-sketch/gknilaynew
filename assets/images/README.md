# Photographs

Drop files in here using these exact names. They appear on the site
immediately — no code changes, no build step.

Anything missing shows a warm tonal placeholder panel with the filename on it,
never a broken-image icon.

## Notes

* **Crop to the ratio.** Every frame is locked to a fixed aspect ratio so the
  layout and the parallax cannot break — but a photo cropped very differently
  will have its edges trimmed to fill the frame.
* **Warm, natural light** suits the ivory/espresso palette. Cool blue-white
  interiors will fight it.
* **Compress before uploading.** Aim under 400 KB each; <https://squoosh.app>
  is free and good. The hero is worth keeping a little larger.
* `project-01.jpg` is shown widest on the home page — put your strongest room there.
* Update the `alt` text when you swap a photo in. It currently describes the
  placeholder typology.
